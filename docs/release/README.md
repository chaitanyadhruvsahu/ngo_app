# Prototype v0.1 — release handover

Status: **release candidate, not yet deployed publicly**. Prepared 11 October 2026.

This is a web-first pilot: fellows and staff use the same HTTPS link in a phone or desktop browser. It is not an app-store release. Start with sample records and a small supervised group; do not upload real identity/bank documents until the NGO has approved its data policy and named a key custodian.

1. [Deployment and operations](deployment.md): accounts, infrastructure, secrets, launch and recovery.
